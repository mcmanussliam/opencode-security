# OpenCode Security

An OpenCode V2 security suite.

## Install

```sh
opencode plugin add github:mcmanussliam/opencode-security
```

That registers all agents, the `/security` command and the skills everywhere — no copying. Later, `opencode plugin update` picks up new versions. Developing the suite itself? Just start OpenCode in this checkout; `.opencode/plugins/` loads the same registration automatically.
